## Reflection intent

Outcome: hand an explicit reflection request to the active runtime or
application reflection flow without loading the retired daily-reflection
command.

Done when: the runtime has selected the appropriate current reflection
capability, or has asked the user to clarify a materially different request.

Evidence: the selected capability and its ordinary completion evidence.

Output: announce the reflection handoff briefly, then continue through the
active runtime's normal skill, app, agent, or tool routing.

This procedure is a routing boundary only. Do not read from `legacy/`, start
the retired `daily-reflection` workflow, or infer a reflection write target.
