## Hi menu

Use this only when `/hi` or `$hi` has no context. The router has seven
registered intents; session-start cues are optional runtime infrastructure and
are not a menu branch. Offer the first menu below, then load only the selected
procedure.

### Choose mode

1. Reflect: reflection handoff, weekly review, or exploration
2. Decide: decision journal
3. Promote: turn working notes into a wiki entry
4. Inspect: run the active harness and wiki checks
5. General: hand the request to the runtime's semantic flow

### Reflect

- Reflection: `protocols/intent-reflection.md`
- Weekly Review: `.claude/commands/weekly.md`
- Explore: `.claude/commands/explore.md`

### Decide

- Decision Journal: `.claude/commands/decision.md`

### Promote

- Promote to Wiki: `.claude/commands/promote.md`

### Inspect

- Lint: `.claude/commands/lint.md`

### General

- Semantic Handoff: `protocols/intent-general.md`

The direct `$system-review` / `/system-review` command remains an explicit
ops surface and is not an intent route.
