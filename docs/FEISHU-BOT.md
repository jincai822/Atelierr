# 飞书机器人使用与后台配置（2026-09-09）

> 代码侧全部就绪；只有两件事要在飞书开放平台后台手工做：
> ① 快捷菜单（应用级配置，API 改不了）；② 新能力的权限 scope 开通 +
> 发布新版本。其余能力开箱即用。

## 机器人能力清单

**你发给机器人（捕获/查询）**

| 你发什么 | 系统做什么 |
|---|---|
| 普通文字 | 捕获为 memory/ 笔记（source: lark），原消息加 ✅ 表情回执 |
| 链接（抖音/小红书…） | 先捕获，links 分发 15 分钟内转写 → 待确认卡 |
| 语音 | 存 attachments/*.ogg → Whisper 转写 → 待确认卡 |
| 图片/文件 | 存 attachments/ → OCR/划重点 → 待确认卡 |
| `搜 关键词` | 回前 5 条匹配卡（标题 + confidence + 打开按钮） |
| `摘要` | 今日摘要卡（正文截断 3000 字 + 打开按钮） |
| `待办` | 进行中待办卡（逐条打开按钮，最多 5 条） |
| `提炼候选` | 今日待提炼清单卡（打开摘要按钮） |
| `周回顾` | 问答进度（已答 N 条）或发起指引 |
| `同步看板` | 手动触发一轮多维表格同步（笔记元数据 → 看板） |
| `菜单` / `帮助` | 指令清单 |

**系统推给你（只报"你不知道的事"）**

- 转写/OCR 完成 → 待确认卡：`在 Obsidian 中打开` / `✅ 确认` /
  `📁 归档…`（先弹目录选择卡，机器推导标「推荐」，点定才移动）
- 新待办 → `✅ 已完成` 按钮（点了删「待办」标签并**回写飞书任务完成**）；
  同时自动建一条**飞书任务**（assignee=你，带截止日期的到点飞书原生
  提醒）；带 📅 截止的待办还会上「Atelierr」日历（全天事件）
- 每日 07:53 → 今日摘要卡（自动置顶并替换昨日置顶）+ 今日复习卡
  （只给标题先想，按钮打开原文再看）
- 每月 1 日 03:00 后 → 月度清理提醒卡 + 「Atelierr」日历全天事件
  （有待删才发；purge 点头永远留在 CLI：memory_cli review → purge）
- 周回顾四问 → 可发**表单卡**（逐问输入框一次提交；见下「表单问答」），
  也可直接回复文字作答（按条回执），回「跳过」定稿
- 抓取/处理失败 → 告警卡（成功不推，防马后炮噪音）

## 表单问答（prompt-open --form）

周回顾等仪式的提问可以推成可填写的表单卡（schema 2.0，逐问输入框，
一次提交收齐全部答案并自动结束问答）：

```bash
set -a; source ~/.config/atelierr/env; set +a
.venv-atelierr/bin/python -m scripts.cli.dispatch_cli prompt-open weekly \
  "本周回顾" --form "这周最有价值的事？" --form "这周卡在哪？" \
  --form "下周重点？" --form "要清理什么？"
```

- 每问可留空（跳过该问）；全空提交不结束会话（可继续文字作答）；
- 文本作答路径始终可用（表单只是更顺手的入口）；
- Atelier 侧的 `$weekly`/`$daily-reflection` 流程如需用表单卡，把
  原来的 prompt-open 调用加上 `--form` 参数即可（那个侧由 Codex 会话维护）。

## 知识库看板（多维表格）

发「同步看板」或跑 `dispatch_cli board`：memory/ 全部笔记的元数据
（标题/目录/标签/层级/confidence/创建日期）单向同步进多维表格应用
「Atelierr 知识库看板」，手机上用表格/看板/日历视图翻库。

- **单向**：表格里改不回写笔记（Obsidian 库是唯一事实源）；
- 首次同步自动建应用和表并把你加为协作者；已删笔记的记录保留不删
  （机器不做删除动作）；
- 想要图表：打开看板 → 仪表盘，手工加一次即可（API 建不了仪表盘）。

## 后台配置：聊天快捷菜单（一次性，约 2 分钟）

让指令变成输入框上方的固定按钮（不用手打）：

1. 打开 [飞书开放平台](https://open.feishu.cn/app) → 选我们的自建应用
   （App ID 见 `~/.config/atelierr/env` 的 `FEISHU_APP_ID`）。
2. 左侧「应用能力」→「机器人」→ 找到「消息菜单」（或「快捷菜单」）
   → 添加菜单项。
3. 逐个添加（菜单名称 = 展示文字，发送内容 = 点完后机器人收到的文本）：

   | 菜单名称 | 发送内容 |
   |---|---|
   | 📋 今日摘要 | `摘要` |
   | ✅ 待办清单 | `待办` |
   | 🧠 提炼候选 | `提炼候选` |
   | 📅 周回顾 | `周回顾` |
   | 📊 同步看板 | `同步看板` |
   | 🔍 搜索用法 | `菜单` |

4. 保存后回到飞书 App：进与机器人的单聊，输入框上方出现菜单栏
   （没有就杀掉飞书重进）。

> 不配菜单也能用：直接手打左列文字（`摘要`、`待办`…）效果完全一样。

## 环境变量（~/.config/atelierr/env）

- `FEISHU_APP_ID` / `FEISHU_APP_SECRET`：自建应用凭证（必填）
- `FEISHU_CHAT_ID`：推送目标单聊（必填）
- `FEISHU_USER_ID`：你的 open_id（可选）。不配也行——你给机器人发过
  消息或点过按钮，系统就认得你（缓存在 state/feishu_account.json）；
  完全不互动过才需要配它
- `FEISHU_VAULT_NAME` / `FEISHU_NOTE_PREFIX`：Obsidian 深链接库名与前缀
  （现值 `atelierr-memory` + `memory/`；改库名必须同步改这里）
