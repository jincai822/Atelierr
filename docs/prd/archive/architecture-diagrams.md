## 📊 图 4：Confidence 计算公式（可视化）

```
输入：Belief 引用的 Wiki Claims

┌────────────────────────────────────────────────┐
│ Belief: "asyncio 适合 I/O 密集型"               │
│                                                 │
│ 引用的 Claims:                                  │
│  • wiki/asyncio.md [C1]     TrustRank: 0.92    │
│  • wiki/concurrency.md [C3] TrustRank: 0.88    │
└────────────────────────────────────────────────┘
                    ↓
                    
步骤 1: 计算平均 TrustRank
┌────────────────────────────────────────────────┐
│ Base Confidence = avg(0.92, 0.88) = 0.90       │
└────────────────────────────────────────────────┘
                    ↓
                    
步骤 2: 多样性加成
┌────────────────────────────────────────────────┐
│ Diversity Bonus = 2 sources × 0.05 = 0.10     │
│ 但来自同一 Wiki，降低为 0.05                   │
└────────────────────────────────────────────────┘
                    ↓
                    
步骤 3: 最终 Confidence
┌────────────────────────────────────────────────┐
│ Final Confidence = min(0.90 + 0.05, 1.0)      │
│                  = 0.85                        │
└────────────────────────────────────────────────┘
```
