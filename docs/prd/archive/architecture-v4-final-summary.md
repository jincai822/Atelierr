## 🧠 注意力机制（v4 核心新增）

### 什么是注意力？

```
Attention = "该关注什么"

例子：
  你有 45 个 Beliefs/Questions/Decisions
  ↓
  信息过载，不知道从哪开始
  ↓
  注意力机制：自动计算"最重要的 3-5 个"
  ↓
  每天早上告诉你："今天关注这 3 个"
```

### 注意力得分计算

```
Attention Score = 
    0.4 × Urgency（紧急性）       例如：明天要决策
  + 0.3 × Impact（影响力）        例如：影响整个架构
  + 0.2 × Novelty（新颖性）       例如：刚发现的问题
  + 0.1 × Confidence Gap（信心缺口） 例如：Confidence 只有 0.4

例子：

Question: "什么时候用 asyncio？"
  • Urgency: 0.9（明天要决策）
  • Impact: 0.9（影响架构）
  • Novelty: 0.8（刚提出）
  • Confidence Gap: 0.9（完全不确定）
  ↓
  Score = 0.4×0.9 + 0.3×0.9 + 0.2×0.8 + 0.1×0.9 = 0.88
  ↓
  高注意力！优先处理！
```

### 注意力清单（每天/每周自动生成）

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📌 今日注意力清单（2026-08-27）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

     Score: 0.88 | 明天要决策
```
